# Open / Niet Open

Gebruik deze lijst als snelle grens voor samenwerken aan Taze.

## Wel open

- Code in de repo
- Content en storeteksten
- UI en UX feedback
- Bugfixes en tests
- Release-notes en documentatie
- PR's en code review

## Niet open

- Stripe secret keys
- Supabase service-role keys
- Microsoft Partner Center credentials
- Google Play service account JSON
- Apple App Store Connect API keys
- Private upload links of tokens
- Billing dashboards
- Store portals zonder noodzaak

## Alleen via owner review

- Pricing
- Publicatie
- Store submissions
- Release artifacts
- Secrets of integraties

## Teamregel

Als iets geld, toegang of publicatie raakt, dan is het niet automatisch open.
Laat de owner eerst beslissen.
